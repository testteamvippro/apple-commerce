## 🏪 CORE TASKS

### ➕ Adding a Product

**In Admin Dashboard:**

1. Click: **Products** menu
2. Click: **Add New Product** button
3. Fill in:
   - **Name**: iPhone 15 Pro
   - **Price**: 28,000,000 (no commas)
   - **Category**: Electronics
   - **Description**: Clear, helpful text
   - **Stock**: How many units available
   - **SKU**: Unique code (optional)
4. Click: **Save Product**
5. Check website - product appears? ✅

**What customers see:**
- Product name, price, description
- Product image (if uploaded)
- "Add to Cart" button

---

### ✏️ Editing a Product

**Change prices/stock quickly:**

1. Click: **Products**
2. Find product name in list
3. Click: **Edit**
4. Change:
   - Price
   - Stock quantity
   - Availability status
5. Click: **Save**
6. Website updates in 5 minutes ✅

**Don't forget:**
- If stock = 0 → change to "Out of Stock"
- If stock < 10 → mark as "Low Stock"
- Check every Friday

---

### 📦 Processing Orders

**When customer buys:**

1. You get notification
2. Click: **Orders** menu
3. See new order with:
   - Customer name
   - Items ordered
   - Total price
   - Status: "Pending"

**To process:**

1. Verify payment received ✅
2. Pack item
3. Get tracking number from courier
4. In order, add tracking number
5. Change status to "Shipped"
6. Customer gets notification ✅

**Order Statuses:**
- **Pending** → New, not yet shipped
- **Processing** → Preparing to ship
- **Shipped** → Sent to customer
- **Delivered** → Customer received
- **Cancelled** → Order cancelled

## 🔧 HOW TO FIX PROBLEMS

### Problem: Website Not Loading

```
Step 1: Check internet (other websites work?)
Step 2: Try different browser
Step 3: Clear browser cache (Settings → Privacy)
Step 4: Restart browser
Step 5: Contact developer if still broken
```

### Problem: Can't Log Into Admin

```
Step 1: Check Caps Lock is OFF
Step 2: Type carefully (no extra spaces)
Step 3: Try different browser
Step 4: Clear cookies (Settings → Privacy)
Step 5: Contact developer to reset password
```

### Problem: Product Not Showing on Website

```
Step 1: Check it exists in admin (Products menu)
Step 2: Check Availability is "Available" (not hidden)
Step 3: Wait 5 minutes for website update
Step 4: Clear browser cache and refresh
Step 5: Contact developer if still missing
```

### Problem: Customer Ordered But No Order Appears

```
Step 1: Check Orders list (refresh page)
Step 2: Search by customer name/email
Step 3: Check payment gateway (Stripe/VNPay)
Step 4: Contact developer with customer email
```

### Problem: Admin Very Slow

```
Step 1: Check internet speed
Step 2: Close other browser tabs/programs
Step 3: Clear browser cache
Step 4: Try mobile device
Step 5: Contact developer
```

### Problem: Can't Download Backup

```
Step 1: Try different browser
Step 2: Disable popup blocker
Step 3: Wait 5 minutes (large backups take time)
Step 4: Check file actually downloaded
Step 5: Contact developer
```

### Problem: Payment Not Working

```
Step 1: Check Stripe/VNPay status online
Step 2: Try different payment method
Step 3: Check admin payment settings enabled
Step 4: Contact developer IMMEDIATELY
```

### Problem: Data Missing/Lost

```
🚨 URGENT - Contact developer NOW
- Don't delete anything else
- Download backup immediately
- Tell developer exactly what's missing
- Developer will restore from backup
```

## 💾 BACKUP & DATA SAFETY

### Download Weekly Backup

**Why:** Protects your business data

**How:**

1. Admin → **System Status** tab
2. Click: **Export Data** button
3. File downloads: `backup_[date].json`
4. Save to:
   - Google Drive ✅
   - Dropbox ✅
   - Email yourself ✅
   - USB stick ✅
5. Keep at least 4 weeks of backups

**File size:** Should be 100 KB - 10 MB (if 0 KB = problem)

## 🆘 EMERGENCY PROCEDURES

### Website Down - Immediate Actions

```
1. Confirm problem (try different device/browser)
2. Check system status page
3. Post on social media: "Temporarily down, fixing now"
4. Email best customers: "Site temporarily unavailable"
5. Contact developer NOW
   → Email, phone, WhatsApp - whatever is fastest
6. Wait - don't try to fix yourself
7. Developer will restore from backup (usually 1 hour)
8. Update customers when back online
```

### Payment Problem - Immediate Actions

```
1. Tell customers to use alternate payment method
2. Take their order anyway (process manually)
3. Contact developer IMMEDIATELY
4. Save all customer info
5. Process refund if needed (through developer)
6. Wait for developer to fix payment system
```

### Data Loss - Immediate Actions

```
🚨 EMERGENCY - DATA LOSS

1. STOP - Don't change anything
2. Download backup NOW
3. Save to 3 different locations
4. Contact developer URGENTLY
   → Include: what's missing, when, how many items
5. Tell developer: "POTENTIAL DATA LOSS"
6. Wait for developer to restore from backup
7. Check data after restore
```
