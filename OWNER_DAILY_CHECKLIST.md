# 📅 Owner's Daily/Weekly/Monthly Checklists

**For: Non-Technical Store Owner - Simple Action Items**

---

## 📋 DAILY CHECKLIST (5-10 minutes)

**Do this EVERY morning:**

### Morning Routine (5 minutes)

```
Time:     7:00 AM - 7:10 AM (or when you start your day)
Duration: 5-10 minutes
Goal:     Make sure everything is working

☐ Open Admin Dashboard
  URL: https://yourdomain.com/admin/dashboard.html
  
☐ Check Overnight Orders
  Click: 📦 Orders
  Look: Any new orders since yesterday?
  Count: How many?
  Status: Are they "Pending"?
  
☐ Check for New Messages
  Dashboard → Notifications section
  Any customer complaints?
  Any system alerts?
  
☐ Quick System Check
  Click: ⚙️ System Status
  Look: Green checkmark next to "Connection"?
  If RED: Contact developer immediately
  
☐ Update Stock (if items sold yesterday)
  Click: 📱 Products
  For each item sold:
    - Find product
    - Click Edit
    - Reduce quantity by 1
    - Click Save
  
☐ Log Out
  Click: 🚪 Logout
  
Total Time: 5-10 minutes ✅
```

### During Business Hours

```
☐ Process New Orders
  Every hour: Check for new orders
  Mark as "Processing" when ready to pack
  
☐ Respond to Customer Inquiries
  Check for messages
  Reply within 2 hours if possible
  
☐ Pack & Ship Orders
  For "Processing" orders:
    1. Pack item
    2. Get tracking number
    3. Update order status to "Shipped"
    4. Add tracking number
    
☐ Monitor Stock Levels
  If product stock < 10:
    - Change availability to "low-stock"
    - Plan to order more from supplier
```

## 📅 WEEKLY CHECKLIST (30 minutes every Sunday)

**Do this ONCE per week on Sunday:**

```
Time:     Sunday 5:00 PM (quiet time, review week)
Duration: 30 minutes
Goal:     Review week's performance and plan ahead
```

### Sunday Evening Review (30 minutes)

```
PART 1: Sales Review (10 minutes)
═════════════════════════════════════

☐ Check Total Revenue
  Analytics → KPI Cards
  Compare with last week
  Higher or lower?
  
☐ Check Order Count
  Analytics → Total Orders
  How many orders this week?
  Average per day?
  
☐ Review Top Sellers
  Analytics → Charts
  Which products sold most?
  Which products sold least?
  
PART 2: Product Management (10 minutes)
═════════════════════════════════════

☐ Check Low Stock Products
  Products → Check all
  Items with < 10 units?
  Items with 0 units?
  
☐ Update Availability
  For low stock: Mark as "low-stock"
  For out: Change to "out-of-stock"
  
☐ Plan Discounts
  Check slow sellers
  Consider adding discount
  Promote during weekend?
  
PART 3: Order Management (5 minutes)
═════════════════════════════════════

☐ Check Pending Orders
  Orders → Filter "Pending"
  Any stuck orders?
  Process immediately
  
☐ Check Shipped Orders
  Orders → Filter "Shipped"
  All have tracking numbers?
  Any customer complaints?
  
PART 4: System Health (5 minutes)
═════════════════════════════════════

☐ System Status Check
  System Status page
  Everything green? ✅
  Any warnings? ⚠️
  
☐ Backup Download
  Click "Export" button
  Save to Google Drive/Dropbox
  Keep safe copy
  
Total Time: 30 minutes ✅
```

## 🚨 EMERGENCY CHECKLIST

**If Something Goes Wrong:**

```
EMERGENCY SITUATION: Website Down
═════════════════════════════════════

Step 1: CONFIRM THE PROBLEM (2 minutes)
  ☐ Try access website from different device
  ☐ Try different browser
  ☐ Try mobile phone
  
  Still not working? → Website is DOWN

Step 2: CHECK SYSTEM STATUS (1 minute)
  ☐ Log into admin: /admin/dashboard.html
  ☐ Can you log in?
    YES: Admin working, frontend may have issue
    NO: Everything down - CALL DEVELOPER NOW
  
  ☐ Check System Status page
    Connection: ✅ Green? → Infrastructure OK
    Connection: ❌ Red? → Infrastructure problem
  
Step 3: INFORM CUSTOMERS (5 minutes)
  ☐ Post on social media:
    "Currently experiencing technical issues.
     We're working to fix it. Back online soon!"
  ☐ Send email to best customers:
    "Temporary maintenance. Site back online in 1 hour."
  ☐ Add notice to store (if physical store):
    "Online store temporarily down. Opening soon."
  
Step 4: CONTACT DEVELOPER (immediately)
  ☐ Email:     [dev@example.com]
  ☐ Phone:     [+84-xxx-xxx-xxx]
  ☐ WhatsApp:  [+84-xxx-xxx-xxx]
  
  Tell them:
  - Website is completely down
  - Customers can't access
  - Time started: _________
  - What you tried: admin access, browser, etc.
  - Impact: Losing sales!
  - Urgent: YES
  
Step 5: WAIT FOR DEVELOPER
  ☐ Don't panic
  ☐ Don't try to fix yourself
  ☐ Developer will restore from backup
  ☐ Typically fixed in < 1 hour
  ☐ Keep phone nearby

═════════════════════════════════════

EMERGENCY SITUATION: Data Lost
═════════════════════════════════════

Step 1: CALL DEVELOPER IMMEDIATELY
  - Data might be recoverable from backup
  - Quick action needed
  - Don't make more changes!
  
Step 2: WAIT FOR RESTORATION
  - Developer restores from latest backup
  - Might lose last 24 hours of data
  - Better than losing everything
  
Step 3: VERIFY DATA
  - Check if all products there
  - Check if recent orders there
  - Document what's missing
  
═════════════════════════════════════

EMERGENCY SITUATION: Payment Issue
═════════════════════════════════════

Step 1: CHECK PAYMENT STATUS
  ☐ Customer says payment failed
  ☐ Check in Orders: is order there?
    YES → Payment received, order confirmed
    NO → Payment failed
  
Step 2: INFORM CUSTOMER
  If payment received:
    "Payment successful! Order confirmed."
  If payment failed:
    "Payment declined. Check your card and try again."
  
Step 3: REFUND IF NEEDED
  ☐ If customer charged twice:
    - Contact developer
    - Provide order details
    - Request refund
  ☐ Developer handles refund
  
═════════════════════════════════════

EMERGENCY SITUATION: Hacked/Compromised
═════════════════════════════════════

Signs:
  - Strange orders appearing
  - Products being deleted
  - Admin password changed by unknown person
  - Unauthorized access attempts

Step 1: DISCONNECT IMMEDIATELY
  ☐ Log out of admin
  ☐ Take website offline if needed
  
Step 2: CALL DEVELOPER (URGENT)
  - Possible security breach
  - System might be compromised
  - Need immediate investigation
  - May need to reset all passwords
  
Step 3: PRESERVE EVIDENCE
  ☐ Don't delete anything
  ☐ Take screenshots of strange activity
  ☐ Note exact time incidents occurred
  
Step 4: NOTIFY CUSTOMERS (if needed)
  - If payment info exposed: alert customers immediately
  - If just orders: explain situation
  - Advise to change passwords
  
Step 5: FOLLOW DEVELOPER INSTRUCTIONS
  - May need full system reset
  - May need password changes
  - May need security audit

═════════════════════════════════════
```
